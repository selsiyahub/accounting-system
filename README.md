# Simple Accounting System

A web-based **Accounting System** built with **PHP (CodeIgniter)** and **MySQL**, designed to manage income, expenses, and overall account balance.

---

## **Features**

- **Transaction Management**
  - Add, edit, and delete financial transactions
  - Transaction details include:
    - Date
    - Description
    - Amount
    - Type (Income / Expense)
    - Category (Salary, Rent, Utilities, etc.)
  
- **Accounts Overview**
  - View total income, total expenses, and current balance
  - Filter transactions by date, category, or type

- **User Interface**
  - Simple and responsive UI for easy navigation
  - Add and manage transactions with minimal effort

---

## **Technologies Used**

- **Backend:** PHP, CodeIgniter 4  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** MySQL  
- **Version Control:** Git, GitHub
